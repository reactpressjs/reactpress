# reactpressjs

> **Write with Focus. Publish with Joy.**
>
> Unscoped global install alias for [`@reactpressjs/reactpress`](https://www.npmjs.com/package/@reactpressjs/reactpress).

[![npm](https://img.shields.io/npm/v/reactpressjs.svg)](https://www.npmjs.com/package/reactpressjs)
[![License: MIT](https://img.shields.io/npm/l/reactpressjs.svg)](./LICENSE)

## Install

```bash
npm install -g reactpressjs
```

This package depends on `@reactpressjs/reactpress` and exposes the same `reactpress` binary.

```bash
mkdir my-site && cd my-site
reactpress init
```

Prefer the scoped package? `npm install -g @reactpressjs/reactpress` is equivalent.
